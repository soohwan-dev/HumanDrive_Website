# HumanDrive website

GitHub Pages-ready static website with 8 supported languages.

- `index.html`: homepage (default language English; manual language selection is remembered).
- `privacy/index.html`: privacy policy, with 8 original translations preserved except requested app name and effective date.
- Links point to explicit HTML files, so opening the pages locally with `file://` also works.
- On GitHub Pages the homepage can be reached at `/` and the policy at `/privacy/`.
- Privacy policy effective date: October 21, 2026.
